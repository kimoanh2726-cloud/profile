## 🌟 Tổng quan (Overview)

Trang Portfolio học thuật và hồ sơ năng lực chuyên nghiệp của **Trần Kim Oanh**. Hệ thống được xây dựng trên nền tảng **Next.js 14 App Router**, **TypeScript**, **Tailwind CSS** và **Framer Motion**, tối ưu hóa trải nghiệm người dùng, tốc độ tải trang và tiêu chuẩn bảo mật cao cấp.

- **Định hướng chuyên môn:** Nghiên cứu Tôn giáo, Nhân học Văn hóa & Phân tích Xã hội.
- **Mục tiêu:** Ứng tuyển thực tập, tham gia các dự án nghiên cứu khoa học và phát triển học thuật.
- **Địa điểm:** Hà Nội, Việt Nam.

## ✨ Điểm nổi bật (Key Features)

### 1. 📜 Kho chứng chỉ phong phú & Trực quan (Certificates & Credentials)
- **38 Chứng chỉ xác thực:**
  - **32 Chứng chỉ quốc tế từ HP Foundation (HP LIFE):** AI, Khoa học dữ liệu, Quản trị Agile, An toàn thông tin, Quản trị doanh nghiệp, Marketing...
  - **IELTS Academic**, Chứng chỉ chuyên sâu **GIS & Phân tích không gian địa lý** (Coursera/University of Toronto).
- **Bộ lọc thẻ (Tag Filter):** Lọc nhanh theo `Kỹ năng`, `Công nghệ`, `Học thuật`, `Việc làm`.
- **Lightbox tương tác:** Hỗ trợ xem ảnh chứng chỉ độ phân giải cao, phóng to / thu nhỏ và điều hướng bàn phím.
- **Liên kết Google Drive:** Tích hợp trực tiếp kho lưu trữ bản scan và PDF gốc.

### 2. 🎨 Hệ thống Giao diện Kép & Đa chế độ (Dual-Theme & Dark/Light Mode)
- **Theme A (Editorial Academic):** Phong cách báo chí học thuật sang trọng, typography *Playfair Display*, gam màu giấy ngà ấm và điểm nhấn hổ phách (*Cognac Amber*).
- **Theme B (Modern / Cyberpunk):** Phong cách công nghệ hiện đại với hiệu ứng kính mờ *Glassmorphism*, typography *Be Vietnam Pro* và điểm nhấn xanh phát sáng (*Electric Cyan*).
- Hỗ trợ đầy đủ **Chế độ Sáng / Tối / Tự động theo hệ điều hành** (Light / Dark / System).

### 3. 🧭 Thanh điều hướng thông minh (Scrollspy Navbar)
- Tự động nhận diện khu vực người dùng đang xem trên màn hình.
- Mục đang xem được **in đậm** và có **thanh gạch chân lượn mượt mà** (*Animated Underline*) theo chuyển động lò xo tự nhiên.
- Tối ưu hóa điều hướng mượt mà cả trên Desktop lẫn Menu điện thoại (Mobile Drawer).

### 4. 🔒 Bảo mật nhiều lớp (Defense-in-depth Security)
- Header bảo mật nghiêm ngặt: **Content Security Policy (CSP)**, **HSTS**, **X-Frame-Options: DENY**, **X-Content-Type-Options: nosniff**.
- Bảo vệ dữ liệu nhạy cảm: Số điện thoại cá nhân và đường dẫn tài liệu nội bộ được bảo vệ nghiêm ngặt, tự động loại bỏ khỏi Client payload.
- Tiêu chuẩn bảo mật: `robots.txt` và `security.txt` đầy đủ.

### 5. 📱 Tối ưu hiển thị đa thiết bị (Responsive Design)
- Hoạt động mượt mà từ màn hình nhỏ thoại di động (360px), máy tính bảng (iPad 768px-1024px), màn hình máy tính (Desktop/Laptop) đến màn hình TV (1080p, 2K, 4K UHD 10-foot UI).

## 🚀 Khởi chạy dự án (Getting Started)

### Cài đặt dependencies:
```bash
npm install
```

### Chạy môi trường phát triển (Development):
```bash
npm run dev
```
Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt để xem trang web.

### Kiểm tra dữ liệu YAML:
```bash
npm run validate
```

### Build cho môi trường Production:
```bash
npm run build
```
